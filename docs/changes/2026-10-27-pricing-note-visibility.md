# Display the reviewed pricing and access limits

Live UI review found that detail pages selected `pricing_details` but never displayed it. A “Free” software badge could therefore hide reviewed qualifications about paid connected accounts, API usage, hosting, optional models or service limits.

Detail pages now expose the exact already-approved pricing/access paragraph. No product data, prices, checkout flow or claim-review record changes. The build artifact gate requires those notes on every published page, in addition to identity and source evidence. This is a correction to information visibility, not a new pricing offer.
