# Correct product misattribution and gate publication

Previously the DeadlineWatch entry attributed AI, MCP and legal deadline-calculation capabilities to an unrelated deadline tracker. Link verification had confirmed only that its website responded. The record is quarantined and its external URL cleared; the detail route rejects the slug even if old data is restored.

New approval and republishing require a trusted, dated primary-source review bound to the exact public claims and destinations. Source snapshots and supporting excerpts are checked again at admission. The badge now says “Links checked.” Existing listings are not represented as capability reviewed. See `docs/catalog-review.md` for the evidence contract, legacy backlog and privileged SQL-write limitation.

Validation: targeted negative/positive admission tests, both admin-boundary tests, TypeScript, full tests, production build and live correction checks. Actual results and release receipts are recorded in the task handoff; a passing build alone is not publication proof.
