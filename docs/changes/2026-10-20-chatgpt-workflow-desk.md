# October 20, 2026 — free ChatGPT workflow desk

Previously the hosted MCP endpoint exposed four text/structured directory tools with dated connection evidence, but no inline comparison interface. This release keeps those contracts and adds one strict, read-only workflow-shortlist tool plus an official MCP Apps resource. It returns real published catalog rows, separate source/link/retrieval dates, explicit untested compatibility, permissions/requirements and a fictional trial checklist. The same interface runs as a standalone web preview with app-specific privacy/support pages.

The endpoint now rejects untrusted browser origins and oversized POST bodies before protocol parsing; native clients without Origin remain supported. The new tool excludes arbitrary text, file intake, arbitrary fetch URLs and extra arguments. Its bounded retrieval errors honestly rather than substituting a sample catalog. The widget uses DOM text nodes, a bundled official bridge and no remote assets. Plugin metadata/skill/review notes describe only the free utility, with no service upsells. Deterministic widget assembly and an allowlist-only reproducible ZIP replace manual packaging.

Compatible dependency updates also removed the existing critical proxy-address advisory and reduced the dependency audit from 19 to 10 findings. Remaining MCP SDK and build-tool advisories require independent security review; no major transport or styling migration was forced.

The published deployment remains unchanged until review. See `docs/chatgpt-app/VERIFICATION.md` for executed checks and remaining release gates.
