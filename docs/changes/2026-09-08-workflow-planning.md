# Workflow planning and assessment journey

The directory previously led visitors from broad tool descriptions to a generic external consultation. A free `/workflow-plan` now produces a browser-only pilot brief for intake follow-up, document collection, or billing preparation. It includes existing-software checks, human review, fictional test cases and an optional capacity estimate. `/workflow-assessment` defines a scoped NYClaw engagement and links to the existing booking page with attribution parameters; fees are agreed before work.

Corrected unsupported claims about MCP privacy, instant setup, and implementation timelines. Checklist copy now describes immediate online access rather than nonexistent email delivery; an ungated link is available. Cards and detail pages use the existing expiry field to distinguish Sponsored from editorial Featured. Pricing removes an unsubstantiated competitor anchor and explains that placement guarantees no traffic or sales. Navigation and sitemap include the new pages.

No new dependencies, model calls, database writes, credentials, paid plans, or checkout behavior. Basic page analytics depends on project activation. Custom events were deliberately omitted because they are unavailable on the current analytics plan.

Verification: 135 tests, production build with 96 generated pages, three workflow paths and 60 × (15 − 5) / 60 = 10 hours calculation checked in browser. Screenshots reviewed at desktop and mobile widths. New content-integrity and capacity tests act as regression gates. Production verification is recorded separately at release time.
