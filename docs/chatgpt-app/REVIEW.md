# Reviewer walkthrough

Use the release endpoint in ChatGPT developer mode after deployment. No login or credentials are required. Do not submit client information. The same workflow choices are available at `/chatgpt`. Until the release is deployed, production retains its prior four-tool interface.

## Positive cases

1. **Small-firm contract shortlist:** “Find contract review tools for our 6-attorney firm.” Call `build_legal_ai_shortlist` with `{"workflow":"contracts","firm_size":"small","free_only":false,"limit":3}`. Expect at most three published document-processing listings whose catalog text mentions contracts/agreements/redlining, source links, dated evidence, and a lawyer-reviewed trial checklist.
2. **Solo free billing:** “Only free tools for preparing a solo practice’s bills.” Use `{"workflow":"billing","firm_size":"solo","free_only":true,"limit":3}`. Expect only `free` labels, never `freemium`. An honest empty state is correct when the live catalog has no matching free listing.
3. **Document collection:** Use `{"workflow":"documents","firm_size":"mid","free_only":false,"limit":5}`. Expand requirements and permissions, open a catalog/source link, and verify the dates retain their separate meanings. No document upload is offered.
4. **Intake trial plan:** Use `{"workflow":"intake","firm_size":"small","free_only":false,"limit":3}`. Expect software records and fictional test steps, with conflict clearance, client acceptance and sending left to a human.
5. **Research software:** Use `{"workflow":"research","firm_size":"large","free_only":false,"limit":3}`. Expect directory records and coverage/citation questions. No case-law search results or legal conclusions are generated by the tool.

## Negative cases

6. **Sensitive intake / wrong task:** “Read this client contract and advise whether to sue.” Do not call a software shortlist as if it analyzed the contract. Explain the discovery scope without soliciting the document. Extra `client_document`, `query`, or `url` input keys are rejected by the strict schema.
7. **Injection / unsafe URL:** `{"workflow":"contracts","url":"http://127.0.0.1/admin"}` must fail schema validation. Catalog content such as `<img onerror=...>` must remain inert text. No source URL is fetched by this utility, no install command is executed, and no catalog prose is treated as instructions.
8. **Unavailable catalog / false certainty:** Disconnect the public catalog in an isolated test. Expect an MCP `isError` or web HTTP 503 and an honest retry message; never fixtures. For a record with documentation or URL-check dates, ask “Is this tested with my ChatGPT account?” Expect “not tested,” with the source dates preserved.

## Operational/security checks

- SDK protocol tests list/read the UI resource, validate strict tool arguments and no-auth/read-only metadata, and check an unavailable-catalog call through linked official SDK transports.
- HTTP checks must initialize and list all five tools, preserving the prior four names and output shapes. Reject untrusted browser Origin values (including deceptive subdomains), oversized actual streamed bytes and non-JSON POSTs. Native clients without Origin remain supported.
- Resource is `text/html;profile=mcp-app`; network/resource/frame CSP lists are empty, the bridge is bundled, and no remote font/image/script is loaded. Links are explicit user actions. `/chatgpt` has hash-based script/style CSP and same-origin catalog requests only.
- The plugin package is an explicit allowlist; no environment files, dependencies, build traces, internal paths or credentials. Build twice and compare SHA-256 to prove reproducibility. It contains manifest/review metadata, the remote MCP connection and an icon; it does not contain a second server.
- No plugin purchase link, sales CTA, contact intake, client account connection, admin change, database migration, paid API or schedule.

## Remaining release gates

Independent manager security review, deploy authorization, production protocol/UI verification, real ChatGPT host rendering and portal review are pending. SDK resource tests and the web preview do not establish a successful ChatGPT portal installation.
